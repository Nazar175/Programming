### Виправлення тесту
Спочатку тест для `count_vowels("Привіт")` очікував `3`, але правильний результат — `2`, оскільки слово містить дві голосні літери.
Було:
```python
self.assertEqual(3, count_vowels("Привіт"))
```
Після виправлення:
```python
self.assertEqual(2, count_vowels("Привіт"))
```
Після виправлення всі тести пройшли успішно (`OK`).

### `subTest`
`subTest` дозволяє перевірити кілька наборів даних в одному тесті та визначити, який саме випадок не пройшов.
У роботі `subTest` використано для перевірки кількості кутів у квадрата, прямокутника та трикутника.
